# Cover implementation plan

> Execute inline, with behavioral tests before integration.

Goal: Implement the accepted first phase: Q enter/exit nearby walls, A/D lateral movement, right mouse expose/aim, release retract, automatic crouch behind low cover.

Architecture: A standalone CoverController resolves eligible faces from existing world-space AABB colliders. It moves the actual player, including when peeking, so the existing visible-mesh bullet collision determines exposure. PlayerController integrates movement/crouch; OperatorAvatar animates the rest pose; the shoulder camera respects wall alignment. No damage-reduction or invulnerability flag.

Files: public/cover-controller.js; public/full3d.js; public/operator-avatar.js; public/index.html; tests/cover.test.cjs; tests/full3d-operator.test.cjs.

Constraints: Keep C/Ctrl crouch, B look-back, existing pistol/reload and bots. Do not teleport across a wall, run around corners automatically, shoot through the covering wall, or stand through an overhead obstruction. Touch buttons supplement keyboard controls. Cover returns to rest on focus loss; death exits cover.

1. Write failing geometry/state tests: acquisition from all faces, distance limit, corners, slide bounds, middle-of-wall aim rejection, physical corner exposure, low cover, blocked corner, and release/exit.
2. Implement CoverController, using a callable collider source so collider updates are respected. Treat cover below 1.35 m as low; taller obstacles require corner peeks because the standing muzzle is approximately 1.42 m. Force standing for low peeks and block firing when the actual muzzle remains inside a collider. Use 0.5 m wall offset, 1.2 m acquisition range, 2 m/s lateral speed, and frame-rate-independent blending. Reject covers below 0.95 m or too narrow for the player.
3. Integrate keys/touch, controller movement, auto crouch, camera and avatar posture. Block fire until exposed and retain muzzle collision against geometry. Add two waist-high training barriers near spawn.
4. Extend real-game smoke tests for Q, strafing, suppressed firing at rest, exposed firing, release, low-cover crouch and camera direction. Run focused tests, syntax and diff checks.
5. Publish one atomic commit against the current remote head; verify deployment status and exact served file content.

Review focus: acquisition through geometry; aiming at wall center; narrow/blocked corners; crouch under ceilings; first-person visibility and physical hit detection. Cover-to-cover travel and rounding corners remain outside this phase.
