# Campo de Fogo - Godot

Protótipo experimental em Godot 4. A versão web permanece preservada na branch main.

## Abrir no Godot

Clone ou baixe a branch `godot-migracao` e importe `godot/project.godot` no editor. Execute com F5.

## Controles

WASD movimentar, mouse girar, Shift correr, Espaço pular, Ctrl agachar, botão direito mirar, esquerdo atirar, R recarregar, Esc liberar cursor.

O personagem ainda é um modelo provisório geométrico. As animações, modelo original Jaime, mapa e multiplayer precisam de migração posterior. Não foi publicado como jogo Godot no navegador.
